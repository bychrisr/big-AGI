## Story
**As a** desenvolvedor do teamAI,
**I want** criar o repositorio bychrisr/teamai com a estrutura de pastas completa definida na arquitetura,
**so that** todos os squads, minds, usuarios e configs tenham um local organizado e versionado no Git.

1. Repositorio `bychrisr/teamai` criado no GitHub como privado
2. Estrutura de pastas `squads-base/mmos-squad/` criada com subdiretorios: minds/, agents/, adapters/, config/, scripts/, workflows/
3. Estrutura de pastas `users/chris_rodrigues/` criada com subdiretorios: squads/, minds/, clone/
4. Estrutura de pastas `users/guilger_oliveira/` criada com subdiretorios: squads/, minds/, clone/

6. Arquivo `squad.yaml` placeholder criado em squads-base/mmos-squad/
7. Estrutura validada com `tree` mostrando todos os diretorios esperados

## Dev Notes

### Comandos bash para criar estrutura completa

```bash
# Criar repo
gh repo create bychrisr/teamai --private --clone
cd teamai

# squads-base
mkdir -p squads-base/mmos-squad/{minds,agents,adapters,config,scripts,workflows}

# users
mkdir -p users/chris_rodrigues/{squads,minds,clone}
mkdir -p users/guilger_oliveira/{squads,minds,clone}

# .gitkeep em diretorios vazios
for dir in \
  squads-base/mmos-squad/{agents,adapters,config,scripts,workflows} \
  users/chris_rodrigues/{minds,clone} \
  users/guilger_oliveira/{minds,clone}; do
  touch "$dir/.gitkeep"
done
```

### Gotchas
- O repo teamai e SEPARADO do repo big-agi (fork). Nao criar dentro do fork.
- Diretorios vazios precisam de .gitkeep para o Git rastrear
- Nao criar memories/ e projects/ dentro de users/ — eles sao excluidos pelo .gitignore e vivem no Supabase
