## Story
**As a** usuario externo (guilger_oliveira),
**I want** acessar o teamAI via dominio proprio de qualquer dispositivo,
**so that** eu possa usar o sistema remotamente sem precisar de VPN ou acesso local.

4. CORS configurado para dominio proprio.
5. Teste de acesso externo de dispositivo diferente validado.

## Dev Notes

### Configuracao Caddy (recomendado)

Caddy e recomendado sobre Nginx por gerar e renovar certificados HTTPS automaticamente sem configuracao adicional.

```
# Caddyfile
teamai.exemplo.com {
    reverse_proxy localhost:3000

    # WebSocket support (necessario para AIX streaming)
    @websocket {
        header Connection *Upgrade*
        header Upgrade websocket
    }
    reverse_proxy @websocket localhost:3000

    # Security headers
    header {
        X-Content-Type-Options nosniff
        X-Frame-Options DENY
        Referrer-Policy strict-origin-when-cross-origin
        Strict-Transport-Security "max-age=31536000; includeSubDomains"
    }

    # Rate limiting
    rate_limit {
        zone dynamic_zone {
            key {remote_host}
            events 100
            window 1m
        }
    }
}
```

### Configuracao Nginx (alternativa)

```nginx
server {
    listen 80;
    server_name teamai.exemplo.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name teamai.exemplo.com;

    ssl_certificate /etc/letsencrypt/live/teamai.exemplo.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/teamai.exemplo.com/privkey.pem;

    # Security headers
    add_header X-Content-Type-Options nosniff;
    add_header X-Frame-Options DENY;
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains";

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Timeouts para streaming
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

### Docker Compose com variaveis

```yaml
# docker-compose.yml
version: '3.8'
services:
  teamai:
    build: .
    ports:
      - "3000:3000"
    env_file:
      - .env
    environment:
      - NODE_ENV=production
      - NEXT_PUBLIC_SUPABASE_URL=${SUPABASE_URL}
      - NEXT_PUBLIC_SUPABASE_ANON_KEY=${SUPABASE_ANON_KEY}
      - SUPABASE_SERVICE_ROLE_KEY=${SUPABASE_SERVICE_ROLE_KEY}
    restart: unless-stopped
```

### Checklist de seguranca

- [ ] Nenhuma API key exposta em variaveis NEXT_PUBLIC_* (exceto anon key do Supabase que e publica por design)
- [ ] SUPABASE_SERVICE_ROLE_KEY nunca exposta no frontend
- [ ] Rate limiting configurado no reverse proxy
- [ ] Firewall do servidor: apenas portas 80, 443, 22 abertas
- [ ] SSH com chave publica (sem senha)
- [ ] Supabase Auth obrigatorio em todas as rotas /api/*

### Testing

- **HTTPS:** Acessar `https://teamai.exemplo.com` e verificar certificado valido (cadeado verde).
- **HTTP redirect:** Acessar `http://teamai.exemplo.com` e verificar redirect para HTTPS.
- **WebSocket:** Iniciar chat com LLM e verificar que streaming funciona (responses aparecem token por token).
- **Mobile:** Acessar do celular via 4G, fazer login, enviar mensagem para LLM.
- **Performance:** Latencia da primeira resposta < 3s; streaming sem interrupcoes.
- **Security:** Tentar acessar /api/* sem JWT -> 401 retornado.
