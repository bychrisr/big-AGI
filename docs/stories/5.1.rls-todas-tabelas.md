## Story
**As a** sistema teamAI,
**I want** Row Level Security habilitado em todas as tabelas de usuario,
**so that** cada usuario acesse apenas seus proprios dados e nenhum dado vaze entre usuarios.

## Acceptance Criteria
1. RLS habilitado em: `user_memories`, `debate_sessions`, `user_clone`, `user_projects`, `user_api_keys`, `user_preferences`.
2. Policy "users see own data" usando `auth.uid()` em todas as tabelas.
3. Testes de isolamento: user A nao acessa dados de user B.
4. Service role bypass para operacoes admin.
5. Migrations SQL versionadas em `supabase/migrations/`.

```sql
ALTER TABLE minds_metadata ENABLE ROW LEVEL SECURITY;

```

### Service Role Bypass

O Supabase automaticamente ignora RLS quando usando a `service_role` key. Operacoes admin (criar minds, debug cross-user) devem usar o client com service role:

```typescript
import { createClient } from '@supabase/supabase-js';

// Client ADMIN — ignora RLS
const supabaseAdmin = createClient(
  process.env.SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
);

// Client USER — respeita RLS
const supabaseUser = createClient(
  process.env.SUPABASE_URL!,
  process.env.SUPABASE_ANON_KEY!,
  { global: { headers: { Authorization: `Bearer ${userJwt}` } } }
);
```

### Schema de referencia das tabelas

```sql
-- user_memories
CREATE TABLE user_memories (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users(id) NOT NULL,
  key text NOT NULL,
  value text NOT NULL,
  confidence float DEFAULT 0.5,
  source text DEFAULT 'explicit', -- 'explicit' | 'checkpoint' | 'pattern'
  created_at timestamptz DEFAULT now(),
  last_applied timestamptz DEFAULT now(),
  UNIQUE(user_id, key)
);
CREATE INDEX idx_user_memories_user ON user_memories(user_id);

-- user_clone
CREATE TABLE user_clone (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users(id) NOT NULL,
  layer text NOT NULL,          -- L1-L8
  content jsonb NOT NULL,
  fidelity float DEFAULT 0.0,
  version text DEFAULT 'v0.1-bootstrap',
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  UNIQUE(user_id, layer)
);
CREATE INDEX idx_user_clone_user ON user_clone(user_id);

-- user_projects
CREATE TABLE user_projects (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users(id) NOT NULL,
  project_name text NOT NULL,
  claude_md text,
  patterns jsonb,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  UNIQUE(user_id, project_name)
);
CREATE INDEX idx_user_projects_user ON user_projects(user_id);

-- user_api_keys
CREATE TABLE user_api_keys (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users(id) NOT NULL,
  provider text NOT NULL,       -- 'anthropic' | 'gemini' | 'openai'
  encrypted_key text NOT NULL,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  UNIQUE(user_id, provider)
);
CREATE INDEX idx_user_api_keys_user ON user_api_keys(user_id);

-- user_preferences
CREATE TABLE user_preferences (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users(id) NOT NULL,
  key text NOT NULL,
  value jsonb NOT NULL,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  UNIQUE(user_id, key)
);
CREATE INDEX idx_user_preferences_user ON user_preferences(user_id);
```

### Testing

**Teste de isolamento (SQL direto):**
```sql
-- Simular user A
SET request.jwt.claims = '{"sub": "user-a-uuid"}';
INSERT INTO user_memories (user_id, key, value)
VALUES ('user-a-uuid', 'test_key', 'secret_value_a');

-- Simular user B — nao deve ver dados de A
SET request.jwt.claims = '{"sub": "user-b-uuid"}';
SELECT * FROM user_memories WHERE key = 'test_key';
-- Esperado: 0 rows
```

**Teste de isolamento (Supabase client):**
```typescript
// Login como user A
const { data: dataA } = await supabaseA
  .from('user_memories')
  .select('*');
// dataA contem apenas memorias de A

// Login como user B
const { data: dataB } = await supabaseB
  .from('user_memories')
  .select('*');
// dataB contem apenas memorias de B — ZERO de A

// Tentativa de acesso cruzado
const { data: cross } = await supabaseB
  .from('user_memories')
  .select('*')
  .eq('user_id', 'user-a-uuid');
// cross = [] (vazio, RLS bloqueia)
```
