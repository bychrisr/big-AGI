## Story
**As a** usuario do teamAI,
**I want** poder importar meu historico de ChatGPT/Gemini e extrair padroes cognitivos automaticamente,
**so that** meu clone comece com um perfil rico baseado em interacoes reais.

## Acceptance Criteria
1. Prompt template em `squads-base/mmos-squad/tools/dna-extraction-prompt.md`.
2. Extrai: `cognitive_patterns`, `communication_style`, `recurring_interests`, `decision_patterns`.
3. Output e YAML valido conforme schema da arquitetura (secao 6.3 do Master Architecture).
4. Documentacao de como exportar de ChatGPT (Settings -> Data Controls -> Export) e Gemini (myaccount.google.com -> Data -> Download).

## Dev Notes
Contexto tecnico:
- **Onde criar:** `squads-base/mmos-squad/tools/dna-extraction-prompt.md` (prompt), `squads-base/mmos-squad/tools/preprocess_export.py` (script), `squads-base/mmos-squad/tools/validate_dna_yaml.py` (validador)
- **Schema YAML:** Deve ser compativel com o formato descrito na secao 6.3 da Master Architecture (`teamAI-Master-Architecture.md`). O output do prompt alimenta as camadas L2-L8 do clone
- **Tamanho do prompt:** O prompt em si deve ser conciso (<2k tokens). O grosso do input sao as conversas exportadas
- **LLM para extracao:** Usar Claude Sonnet com context window de 200k — permite analisar ~150k tokens de conversas de uma vez
- **Pre-processamento:** ChatGPT export e um zip com `conversations.json` (array de objetos com `title`, `mapping`). Cada mensagem tem `author.role` ("user"/"assistant") e `content.parts`
- **Validacao YAML:** Usar `pyyaml` para parse + checagem de campos obrigatorios

### Testing
