## Dev Notes

### Comandos exatos para criar symlinks

```bash
# A partir da raiz do repo teamai

# chris_rodrigues
cd users/chris_rodrigues/squads/
ln -s ../../../squads-base/mmos-squad ./mmos-squad
cd -

# guilger_oliveira
cd users/guilger_oliveira/squads/
ln -s ../../../squads-base/mmos-squad ./mmos-squad
cd -

# Squads proprios
mkdir -p users/chris_rodrigues/squads/kaven-squad
touch users/chris_rodrigues/squads/kaven-squad/.gitkeep

mkdir -p users/guilger_oliveira/squads/psicologia-squad
touch users/guilger_oliveira/squads/psicologia-squad/.gitkeep

# Adicionar ao Git
git add users/chris_rodrigues/squads/mmos-squad
git add users/guilger_oliveira/squads/mmos-squad
git add users/chris_rodrigues/squads/kaven-squad/
git add users/guilger_oliveira/squads/psicologia-squad/
git commit -m "feat: add user symlinks to mmos-squad and project squads"
```

### Validacao de symlinks

```bash
# Verificar que o symlink e relativo (nao absoluto)
readlink users/chris_rodrigues/squads/mmos-squad
# Esperado: ../../../squads-base/mmos-squad

# Verificar que resolve corretamente
readlink -f users/chris_rodrigues/squads/mmos-squad
# Esperado: /path/to/repo/squads-base/mmos-squad

# Verificar que o Git rastreia como symlink
git ls-files -s users/chris_rodrigues/squads/mmos-squad
# Esperado: 120000 (modo symlink)
```

### Teste de clone fresh

```bash
# Em diretorio temporario
cd /tmp
git clone git@github.com:bychrisr/teamai.git teamai-test
cd teamai-test

# Verificar symlinks
ls -la users/chris_rodrigues/squads/mmos-squad
# Esperado: mmos-squad -> ../../../squads-base/mmos-squad

# Verificar que resolve
ls users/chris_rodrigues/squads/mmos-squad/minds/
# Esperado: lista dos minds criados na Story 1.2

# Limpar
rm -rf /tmp/teamai-test
```

### Gotchas
- Symlinks DEVEM ser relativos (`../../../squads-base/mmos-squad`), NUNCA absolutos. Absolutos quebram em qualquer outra maquina.
- Git em Linux preserva symlinks nativamente. Em Windows com Git Bash, symlinks podem nao funcionar — mas o deploy e Docker (Linux), entao nao e problema.
- O symlink aponta para o DIRETORIO mmos-squad inteiro, nao para arquivos individuais.
- `git add` de um symlink adiciona o link, nao o conteudo do target. Isso e o comportamento desejado.
- Nao confundir: `users/*/squads/mmos-squad/` e symlink (compartilhado), `users/*/squads/kaven-squad/` e diretorio real (proprio do usuario).
