### Script validate-registry.sh

```bash
#!/bin/bash
set -euo pipefail

REGISTRY="squads-base/registry.yaml"
errors=0

echo "=== Validating teamAI Registry ==="

# Check registry exists
if [ ! -f "$REGISTRY" ]; then
  echo "FATAL: $REGISTRY not found"
  exit 1
fi

# Validate squad paths exist
echo "Checking squad paths..."
for path in \
  "squads-base/mmos-squad" \
  "users/chris_rodrigues/squads/kaven-squad" \
  "users/guilger_oliveira/squads/psicologia-squad"; do
  if [ ! -d "$path" ] && [ ! -L "$path" ]; then
    echo "ERROR: Squad path not found: $path"
    errors=$((errors + 1))
  else
    echo "  OK: $path"
  fi
done

# Validate user paths exist
echo "Checking user paths..."
for user in chris_rodrigues guilger_oliveira; do
  for subdir in minds clone; do
    path="users/$user/$subdir"
    if [ ! -d "$path" ]; then
      echo "ERROR: User path not found: $path"
      errors=$((errors + 1))
    else
      echo "  OK: $path"
    fi
  done
done

# Validate symlinks
echo "Checking symlinks..."
for user in chris_rodrigues guilger_oliveira; do
  link="users/$user/squads/mmos-squad"
  if [ -L "$link" ]; then
    target=$(readlink "$link")
    if [ -d "$link" ]; then
      echo "  OK: $link -> $target (resolves)"
    else
      echo "ERROR: Broken symlink: $link -> $target"
      errors=$((errors + 1))
    fi
  else
    echo "ERROR: Not a symlink: $link"
    errors=$((errors + 1))
  fi
done

# Validate minds count
echo "Checking minds count..."
actual_count=$(find squads-base/mmos-squad/minds/ -mindepth 1 -maxdepth 1 -type d | wc -l)
echo "  Minds found: $actual_count"

# Summary
echo ""
if [ $errors -eq 0 ]; then
  echo "=== All validations passed ==="
else
  echo "=== Found $errors errors ==="
  exit 1
fi
```

### Gotchas
- O minds_count no registry.yaml deve bater com o numero real de diretorios em minds/. O script de validacao verifica isso.
- Paths no registry sao relativos a raiz do repo, nao absolutos
- O campo `requires` indica dependencia: kaven-squad depende de mmos-squad (pode consultar minds via symlink)
- yamllint pode reclamar de linhas longas — configurar com `line-length: disable` se necessario

### Testing
- Framework: bash (scripts de validacao)
- Localizacao: scripts/validate-registry.sh
- Cenarios: Todos os paths existem; symlinks resolvem; minds_count correto
- Edge cases: Path que existe mas e arquivo (nao diretorio); symlink que aponta para lugar errado; registry com squad nao criado
