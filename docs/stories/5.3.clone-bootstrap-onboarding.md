## Story
**As a** novo usuario do teamAI,
**I want** que apos o onboarding meu clone inicial seja gerado automaticamente,
**so that** o sistema ja me conheca minimamente e possa personalizar interacoes desde o primeiro uso.

## Acceptance Criteria
1. Bootstrap roda automaticamente ao fim do onboarding.
2. Respostas das perguntas mapeadas para `user_clone` no Supabase + Git (`users/{username}/clone/`).
3. Fidelidade calculada (~35% baseline para onboarding sem export).
4. Notificacao ao usuario: "Criei um perfil inicial seu. Vou melhorando conforme conversamos."
5. Clone em `users/{username}/clone/` com versao inicial (`v0.1-bootstrap`).
6. Se usuario forneceu export de LLM: processar via DNA Mental extraction e aumentar fidelidade.

### Funcao de bootstrap

```typescript
interface CloneLayer {
  layer: string;
  name: string;
  fidelity: number;
  source: string;
  data: Record<string, unknown>;
}

async function bootstrapClone(
  userId: string,
  username: string,
  answers: OnboardingAnswers
): Promise<{ fidelity: number }> {
  const layers: CloneLayer[] = [
    {
      layer: 'L1',
      name: 'identidade',
      fidelity: answers.display_name ? 0.5 : 0,
      source: 'onboarding',
      data: {
        display_name: answers.display_name,
        work_area: answers.work_area,
      },
    },
    {
      layer: 'L5',
      name: 'interesses_e_foco',
      fidelity: answers.interests.length > 0 ? 0.6 : 0,
      source: 'onboarding',
      data: {
        primary_interests: answers.interests,
        inspirations: answers.inspirations,
        current_challenge: answers.current_challenge,
      },
    },
    {
      layer: 'L6',
      name: 'valores',
      fidelity: answers.inspirations.length > 0 ? 0.3 : 0,
      source: 'onboarding',
      data: {
        inferred_from_inspirations: answers.inspirations,
      },
    },
    {
      layer: 'L8',
      name: 'meta',
      fidelity: 0.4,
      source: 'onboarding',
      data: {
        ai_experience: answers.ai_experience,
        public_profiles: answers.public_profiles,
      },
    },
  ];

  // Salvar no Supabase
  for (const layer of layers) {
    await supabase
      .from('user_clone')
      .upsert({
        user_id: userId,
        layer: layer.layer,
        content: layer.data,
        fidelity: layer.fidelity,
        version: 'v0.1-bootstrap',
      }, { onConflict: 'user_id,layer' });
  }

  // Calcular fidelidade total
  const weights: Record<string, number> = {
    L1: 0.10, L2: 0.15, L3: 0.10, L4: 0.15,
    L5: 0.20, L6: 0.10, L7: 0.10, L8: 0.10,
  };

  const totalFidelity = layers.reduce((sum, l) => {
    const weight = weights[l.layer] || 0;
    return sum + (l.fidelity * weight);
  }, 0);

  return { fidelity: totalFidelity };
}
```

### Processamento de export de LLM

```typescript
async function processLLMExport(
  userId: string,
  exportFile: Buffer,
  platform: 'chatgpt' | 'gemini'
): Promise<void> {
  // 1. Parse do arquivo
  const conversations = platform === 'chatgpt'
    ? parseChatGPTExport(exportFile)
    : parseGeminiExport(exportFile);

  // 2. Rodar DNA Mental extraction via Anthropic API
  const extraction = await extractDNAMental(
    conversations,
    userId
  );

  // 3. Merge com clone existente
  await mergeExtractionWithClone(userId, extraction);

  // 4. Recalcular fidelidade
  await recalculateFidelity(userId);
}
```
