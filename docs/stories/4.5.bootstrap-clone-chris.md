## Story
**As a** Chris (admin do teamAI),
**I want** gerar meu clone inicial combinando onboarding e DNA extraction,
**so that** o sistema tenha um perfil cognitivo funcional desde o primeiro dia.

## Acceptance Criteria
1. Script `scripts/bootstrap-clone.py` processa respostas de onboarding.
2. Script processa exports de LLMs via dna-extraction-prompt.
3. Gera `users/chris_rodrigues/clone/clone-v0.1.yaml` com fidelidade medida.
4. Milestone notifications implementadas (40%, 60%, 80%, 94%) conforme `check_clone_milestone()`.
5. Clone commitado no Git com tag de versao (`clone-chris-v0.1`).

## Dev Notes
Contexto tecnico:
- **Onde criar:** `scripts/bootstrap-clone.py` (na raiz do repo teamai, nao dentro de squads)
- **Dependencia:** Usa output do dna-extraction-prompt (Story 4.4) como input. Usa `MemoryStore` (Story 4.1) para espelhar no Supabase
- **Onboarding data:** JSON com respostas das 5-8 perguntas do pipeline (secao 11 da arquitetura): `{ "nome": "Chris", "como_prefere": "Chris", "area": "tecnologia", "interesses": ["automacao", "sistemas escalaveis", "clonagem cognitiva"], "inspiracoes": ["Naval Ravikant", "Paul Graham"], "usa_ia": true, "desafio": "escalar operacao sem perder qualidade" }`
- **Clone YAML layers (L1-L8):** L1=identidade, L2=cognitive_patterns, L3=communication+interests, L4=decision_patterns, L5=expertise, L6=current_context, L7=behavioral_feedback, L8=referencias_externas
- **Supabase table `user_clone`:** Schema: `(user_id uuid, layer text, content jsonb, fidelity float, version text, created_at timestamptz)` com RLS `user_id = auth.uid()`
- **Git operations:** Usar `subprocess.run(['git', ...])` para add, commit e tag. Script assume que esta rodando dentro do repo
- **Fidelidade meta:** Bootstrap com onboarding + ChatGPT export deve atingir ~35-40%. Fidelidade sobe com checkpoints silenciosos (Story 4.2) ao longo do tempo
