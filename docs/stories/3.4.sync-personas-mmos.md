## Story
**As a** usuario do teamAI,
**I want** que as personas do big-AGI sejam sincronizadas automaticamente com os minds do MMOS,
**so that** eu veja os minds disponiveis como personas sem configuracao manual.

## Acceptance Criteria
1. Script de sync le `minds/*/metadata.yaml` do repo teamai
2. Gera personas no formato big-AGI (`SimplePersona`: id, name, systemPrompt)
3. Sync executado no build/startup
4. Personas mostram nome e specialty do mind

## Dev Notes

### Arquivos relacionados no big-AGI
- `src/apps/personas/store-app-personas.ts` — store Zustand com `SimplePersona[]`, persistido em localStorage
- `src/apps/personas/AppPersonas.tsx` — componente principal que renderiza lista de personas
- `src/apps/personas/creator/` — componentes de criacao de personas (Creator, FromText, FromYouTube)

### Padroes existentes a seguir
- Store de personas: Zustand `create()` com `persist()` middleware
- SimplePersona tem `MAX_SAVED_PROMPTS = 100` — garantir que sync nao ultrapasse
- Personas sao identificadas por `id` (UUID gerado por `agiUuid('persona-simple')`)
- Para minds sincronizados, usar ID deterministic baseado no mind id: `'mmos-mind-' + mind.id`

### APIs e tipos relevantes
- `SimplePersona` interface: `{ id, name?, systemPrompt, creationDate, pictureUrl?, inputProvenance?, inputText, llmLabel? }`
- `SimplePersonaProvenance`: `{ type: 'youtube', url, title?, thumbnailUrl? } | { type: 'text' }`
- `prependSimplePersona()`: funcao existente para adicionar persona ao store

### Estrutura de um mind no repo teamai
```
squads-base/mmos-squad/minds/paul_graham/
  metadata.yaml        # { id: paul_graham, name: "Paul Graham", specialty: "Startups & Essays", token_budget: 15000, tags: [strategy, startups] }
  system_prompt.md     # System prompt completo do mind
  kb/                  # Knowledge base (nao necessario para sync de personas)
```
