## Story
**As a** novo usuario do teamAI,
**I want** ser guiado por um agent "Alex" que me conheca em 5-8 perguntas rapidas,
**so that** o sistema tenha contexto sobre mim desde o primeiro uso e eu nao precise configurar tudo manualmente.

## Acceptance Criteria
1. Fluxo completo de onboarding implementado com agent "Alex".
2. Perguntas apresentadas uma a uma (conversacional, nao formulario).
3. Respostas salvas em `user_preferences` e `user_clone`.
4. Pergunta sobre exportacao de LLMs com instrucao de como exportar (ChatGPT, Gemini).
5. Pergunta sobre API key com link para Anthropic.
6. Ao final: confirmacao de tudo configurado com resumo ao usuario.
7. Onboarding completo em < 10 minutos.

## Dev Notes

### System Prompt do Agent Alex

```markdown
# Alex — Onboarding Agent

Voce e o Alex, o assistente de configuracao do teamAI.

## Sua missao
Conhecer o novo usuario em 5-8 perguntas rapidas e configurar o sistema para ele.
Seja amigavel, direto e eficiente. O onboarding deve levar menos de 10 minutos.

## Personalidade
- Amigavel mas nao excessivamente entusiasmado
- Direto — sem enrolacao
- Explica o "por que" de cada pergunta quando relevante
- Adapta linguagem ao estilo do usuario

## Fluxo de perguntas

1. "Qual e o seu nome? Como voce prefere ser chamado?"
   -> Salva em: user_preferences.display_name

2. "Em que area voce trabalha?"
   -> Salva em: user_preferences.work_area

3. "Quais sao seus 2-3 maiores interesses agora?"
   -> Salva em: user_preferences.interests (array)

4. "Voce acompanha alguem que te inspira muito? Pode ser autor,
   empreendedor, criador de conteudo..."
   -> Salva em: user_preferences.inspirations (array)
   -> Usa para sugerir minds relevantes do MMOS

5. "Voce tem perfil publico? Instagram, YouTube, site, blog..."
   -> Salva em: user_preferences.public_profiles (object)
   -> Opcional

6. "Voce ja usa alguma IA no dia a dia? ChatGPT, Gemini, Claude..."
   -> Se sim: "Sabia que voce pode exportar seu historico e eu construo
      um perfil seu MUITO mais completo? Vou te mostrar como."
   -> Instrucoes de export por plataforma
   -> Salva em: user_preferences.ai_experience

7. "Qual e seu maior desafio agora? Pode ser profissional ou pessoal."
   -> Salva em: user_preferences.current_challenge

## Pos-perguntas
- Solicitar API key da Anthropic (obrigatorio)
- Resumir tudo que foi configurado
- Notificar que clone inicial sera gerado
```

### Mapeamento de respostas para user_preferences

```typescript
interface OnboardingAnswers {
  display_name: string;
  work_area: string;
  interests: string[];
  inspirations: string[];
  public_profiles: {
    instagram?: string;
    youtube?: string;
    website?: string;
  };
  ai_experience: {
    uses_ai: boolean;
    platforms?: string[];
    export_provided?: boolean;
  };
  current_challenge: string;
}

// Salvar no Supabase
async function saveOnboardingAnswers(
  userId: string,
  answers: OnboardingAnswers
) {
  const entries = Object.entries(answers).map(
    ([key, value]) => ({
      user_id: userId,
      key,
      value: JSON.stringify(value),
    })
  );

  await supabase
    .from('user_preferences')
    .upsert(entries, { onConflict: 'user_id,key' });
}
```

### Deteccao de usuario novo

```typescript
// No middleware ou layout principal do big-AGI
async function checkOnboardingStatus(userId: string) {
  const { data } = await supabase
    .from('user_preferences')
    .select('key')
    .eq('user_id', userId)
    .eq('key', 'onboarding_completed');

  if (!data || data.length === 0) {
    // Redirecionar para /onboarding
    return { needsOnboarding: true };
  }
  return { needsOnboarding: false };
}
```

### Testing

- **Fluxo completo:** Criar usuario novo no Supabase Auth, verificar que e redirecionado para onboarding, responder todas as perguntas, verificar dados salvos em `user_preferences` e `user_clone`.
- **Fluxo parcial:** Usuario abandona no meio — dados ja respondidos sao salvos, proximo login retoma de onde parou.
- **API key invalida:** Ao inserir key invalida, sistema rejeita e pede novamente.
- **Export de LLM:** Upload de arquivo JSON do ChatGPT e processado corretamente.
- **Tempo:** Medir tempo total do onboarding — meta < 10 minutos.
