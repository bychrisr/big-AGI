## Story
**As a** sistema teamAI,
**I want** que agents observem padroes de comportamento do usuario em background,
**so that** preferencias implicitas sejam capturadas sem exigir comandos explicitos.

## Acceptance Criteria
1. Triggers implementados: usuario corrigiu output, pediu reformatacao, expandiu tema >5 turnos, retomou topico apos >3 dias.
2. `SilentCheckpoint.analyze(session)` retorna `List[MemoryCandidate]` com `key`, `value`, `confidence`.
3. Apenas candidates com `confidence > 0.65` sao commitados via `MemoryStore.record_explicit()` com `source='checkpoint'`.
4. Execucao assincrona — nao bloqueia a sessao do usuario.
5. Nao duplica memorias existentes — verifica se a chave ja existe antes de inserir.

## Dev Notes
Contexto tecnico:
- **Onde criar:** `squads-base/mmos-squad/scripts/silent_checkpoint.py` e `memory_candidate.py`
- **Dependencia:** Usa `MemoryStore` da Story 4.1 — importar de `memory_store.py`
- **Session data:** Recebe objeto `Session` com `turns: List[Turn]`, `user_id: str`, `started_at: datetime`, `topic: str`. Estrutura de Turn: `(role: str, content: str, timestamp: datetime)`
- **Deteccao de padroes:** Usar regex simples para v1 — nao LLM. Patterns: "nao, eu quis dizer", "na verdade", "corrija", "refaz", "coloca em tabela", "formato bullet"
- **Async:** `asyncio` padrao do Python 3.13. Se o runtime nao for async, usar `threading.Thread` como fallback
- **Threshold de confidence:** 0.65 e configuravel — definir como constante `CONFIDENCE_THRESHOLD = 0.65` no topo do arquivo
- **Nao duplicar:** Query `user_memories` por `(user_id, key)` antes de inserir. Se existe e confidence existente >= nova, skip
