## Story
**As a** usuario do teamAI,
**I want** falar "grava na memoria que..." e o agent salvar essa informacao permanentemente,
**so that** minhas preferencias sejam lembradas em todas as sessoes futuras.

## Acceptance Criteria
1. `MemoryStore.record_explicit(user_id, key, value, source='explicit')` salva no Supabase `user_memories`.
2. `confidence=1.0` para `source='explicit'` (usuario declarou diretamente).
3. Comando detectado no chat: frases como "grava na memoria que...", "lembra que eu...", "anota que...".
4. Agent responde confirmando o que foi gravado (ex: "Gravado: preferencia_formato = numeros primeiro, depois narrativa").
5. Chave normalizada em `snake_case` (ex: "preferencia de formato" -> "preferencia_formato").
6. Upsert: se a chave ja existe para o usuario, atualiza o valor e `last_applied`.

## Dev Notes
Contexto tecnico:
- **Onde criar:** `squads-base/mmos-squad/scripts/memory_store.py` e `memory_command_detector.py`
- **Supabase client:** usar `supabase-py` (pip install supabase). Client inicializado com URL e service_role_key do `.env`
- **Schema da tabela:** PK composta `(user_id, key)` permite upsert natural via `supabase.table('user_memories').upsert()`
- **Normalizacao de chave:** usar `unicodedata.normalize('NFD')` para remover acentos, `re.sub` para snake_case
- **RLS:** A policy precisa ser identica ao padrao usado em `debate_sessions` (Epic 2 Story 2.4)
- **Upsert semantics:** `on_conflict='user_id,key'` no Supabase Python client
