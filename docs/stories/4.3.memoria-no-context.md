## Story
**As a** usuario do teamAI,
**I want** que agents usem minhas memorias salvas para personalizar respostas,
**so that** cada sessao fique mais alinhada com minhas preferencias.

## Acceptance Criteria
1. No inicio de cada sessao, top-N memorias relevantes carregadas do Supabase.
2. Memorias injetadas no system prompt do agent/mind como bloco estruturado.
3. Memorias mais recentes e de alta confidence tem prioridade no ranking.
4. Maximo de 2k tokens para memorias injetadas (nao estourar context window).
5. Agent usa memorias nas respostas (ex: formata output conforme preferencia gravada).

## Dev Notes
Contexto tecnico:
- **Onde criar:** `squads-base/mmos-squad/scripts/memory_context.py` (Python) e `app/api/memory/route.ts` (TypeScript, no big-AGI fork)
- **Dependencia:** Usa `MemoryStore` da Story 4.1
- **Token estimation:** Para v1, usar heuristica `len(text.split()) / 0.75` (1 token ~ 0.75 palavras em portugues). Nao precisa de tiktoken
- **Ponto de injecao no big-AGI:** O system prompt e montado em `src/modules/aix/` antes de enviar para o provider. Buscar onde o `systemMessage` e concatenado no fluxo de chat
- **Max tokens:** 2000 tokens e o default, mas configuravel. Em debates com muitos minds, pode ser reduzido para 1000
- **Formato do bloco:** Markdown puro — o LLM interpreta naturalmente
- **Rota /api/memory:** Seguir padrao identico ao `/api/debate` (Epic 2 Story 2.5) — mesmo middleware de auth, mesma estrutura de response
