## Story
**As a** usuario do teamAI,
**I want** iniciar um debate entre minds selecionados usando a interface Beam,
**so that** eu receba perspectivas de multiplos thought leaders sobre o mesmo topico.

## Acceptance Criteria
1. UI mostra "Start Debate" com selecao de minds
2. Beam intercepta request e injeta system prompt do mind selecionado
3. Chamadas vao para `/api/debate` (nao diretamente para LLM provider)
4. Resultado mostrado no formato Beam existente (scatter/gather UI)

## Dev Notes

### Arquivos relacionados no big-AGI (Beam system)
- `src/modules/beam/store-beam_vanilla.ts` — store principal do Beam (vanilla Zustand)
  - `RootStoreSlice`: state base (isOpen, inputHistory, etc.)
  - `open()` linha 76: funcao que inicializa Beam com chat history
- `src/modules/beam/scatter/beam.scatter.ts` — logica de scatter (enviar para multiplos modelos)
  - `BRay` interface linha 20: representa um ray (modelo individual)
  - `rayScatterStart()` linha 43: inicia scatter para um ray
  - `splitSystemMessageFromHistory()` linha 58: separa system message
- `src/modules/beam/scatter/BeamRay.tsx` — componente visual de um ray
- `src/modules/beam/scatter/BeamScatterPane.tsx` — painel com todos os rays
- `src/modules/beam/scatter/BeamRayGrid.tsx` — grid de rays
- `src/modules/beam/gather/` — logica de gather (fusao de respostas)
- `src/modules/beam/BeamView.tsx` — view principal do Beam
- `src/modules/beam/beam.config.ts` — configuracao (SCATTER_RAY_DEF, etc.)

### Padroes existentes a seguir
- Beam usa vanilla Zustand store (nao React store) para performance
- BRay tem `rayLlmId: DLLMId | null` — no modo debate, pode ser null (mind no lugar de LLM)
- Scatter usa `aixChatGenerateContent_DMessage_FromConversation` para chamadas — no debate, substituir por chamada a `/api/debate`
- UI usa Material-UI Joy

### APIs e tipos relevantes
- `BRay` em `beam.scatter.ts`: `{ rayId, status, message, rayLlmId, scatterIssue?, genAbortController?, userSelected, imported }`
- `BeamStore` em `store-beam_vanilla.ts`: `RootStoreSlice & GatherStoreSlice & ScatterStoreSlice`
- `DMessage` em `src/common/stores/chat/chat.message.ts`: tipo de mensagem
- `MindMetadata` (definido na Story 3.3): `{ id, name, specialty, tags, tokenBudget, source }`

### Estrategia de extensao do Beam
O Beam existente funciona com LLMs (cada ray = um LLM diferente). Para debates:
1. Manter o Beam original intacto
2. Adicionar `debateMode` como extensao (nao substituicao)
3. Em debate mode, cada ray = um mind (nao um LLM)
4. A diferenca esta no scatter: ao inves de chamar LLM diretamente, chama `/api/debate` com system prompt do mind
5. Gather funciona igual (fusao de respostas)
