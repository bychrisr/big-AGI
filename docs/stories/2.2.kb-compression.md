## Story
**As a** sistema teamAI,
**I want** comprimir a KB de cada mind para apenas os chunks relevantes ao topico do debate,
**so that** o uso de tokens caia de ~40k para ~5-8k por mind, viabilizando debates com multiplos minds dentro do context window.

## Acceptance Criteria
1. Funcao `extract_relevant_chunks(kb_path, topic, max_chunks=10)` implementada
2. Reducao efetiva de tokens: KB de ~40k tokens comprimida para ~5-8k tokens
3. Chunks ranqueados por relevancia ao topico usando keyword matching
4. Chunks separados por delimitador claro (`---`)
5. Funcao retorna string vazia quando KB esta vazia ou nao existe
6. Integracao com DebateEngine — KB comprimida usada em vez de KB completa
7. Testes cobrindo: KB normal, KB vazia, topico sem matches, max_chunks variavel

### Implementacao do kb_compressor.py

```python
from pathlib import Path


def extract_relevant_chunks(
    kb_path: str | Path,
    topic: str,
    max_chunks: int = 10,
) -> str:
    """Extrai chunks mais relevantes de uma KB para um topico.

    Usa keyword matching para ranquear chunks por relevancia.
    Reduz KB de ~40k tokens para ~5-8k tokens.

    Args:
        kb_path: Caminho para o diretorio kb/ do mind.
        topic: Topico do debate para filtrar relevancia.
        max_chunks: Numero maximo de chunks a retornar.

    Returns:
        String com chunks relevantes separados por '---'.
        String vazia se KB nao existe ou esta vazia.
    """
    kb_dir = Path(kb_path)
    if not kb_dir.exists() or not kb_dir.is_dir():
        return ""

    chunks = _load_chunks(kb_dir)
    if not chunks:
        return ""

    topic_keywords = _extract_keywords(topic)
    scored = _score_chunks(chunks, topic_keywords)
    top_chunks = scored[:max_chunks]

    return "\n\n---\n\n".join(chunk for _, chunk in top_chunks)


def _load_chunks(kb_dir: Path) -> list[str]:
    """Carrega todos os arquivos .md do diretorio kb/."""
    files = sorted(kb_dir.glob("*.md"))
    return [f.read_text().strip() for f in files if f.stat().st_size > 0]


def _extract_keywords(topic: str) -> list[str]:
    """Extrai keywords do topico, removendo stopwords comuns."""
    stopwords = {
        "a", "o", "e", "de", "do", "da", "em", "um", "uma",
        "para", "com", "que", "como", "por", "no", "na",
        "the", "and", "or", "of", "to", "in", "for", "is",
        "on", "at", "by", "an", "it", "as", "be", "are",
    }
    words = topic.lower().split()
    return [w for w in words if w not in stopwords and len(w) > 2]


def _score_chunks(
    chunks: list[str],
    keywords: list[str],
) -> list[tuple[int, str]]:
    """Ranqueia chunks por contagem de keywords."""
    scored = []
    for chunk in chunks:
        chunk_lower = chunk.lower()
        score = sum(chunk_lower.count(kw) for kw in keywords)
        scored.append((score, chunk))
    scored.sort(key=lambda x: x[0], reverse=True)
    return scored
```

### Modificacao no MindLoader

```python
# mind_loader.py — metodo atualizado
def load_kb(
    self,
    mind_slug: str,
    topic: str | None = None,
    max_chunks: int = 10,
) -> str:
    """Carrega KB do mind, opcionalmente comprimida por topico."""
    kb_dir = self.base / mind_slug / "kb"
    if topic:
        return extract_relevant_chunks(kb_dir, topic, max_chunks)
    # Fallback: carrega tudo (sem compressao)
    if not kb_dir.exists():
        return ""
    chunks = sorted(kb_dir.glob("*.md"))
    return "\n\n---\n\n".join(f.read_text() for f in chunks)
```

### Metricas de reducao esperadas

| Cenario | Antes | Depois | Reducao |
|---------|-------|--------|---------|
| KB hormozi (60k tokens) | 60,000 | 8,000 | ~87% |
| KB standard (40k tokens) | 40,000 | 5,000 | ~87% |
| KB pequena (10k tokens) | 10,000 | 5,000 | ~50% |
| KB vazia | 0 | 0 | N/A |

### Gotchas
- Keyword matching e a implementacao v1 (simples e rapida). Futuramente pode evoluir para embeddings/semantic search, mas nao neste momento.
- Chunks devem ser arquivos .md separados no diretorio kb/. Um unico arquivo grande nao sera particionado automaticamente.
- A funcao retorna string vazia (nao None) para KB vazia — facilita concatenacao no system prompt.
- max_chunks=10 e o default, mas para minds com KB enorme (hormozi) pode ser ajustado.
- O delimitador `---` entre chunks ajuda o LLM a distinguir fontes.

### Testing
- Framework: pytest
- Localizacao: squads-base/mmos-squad/tests/test_kb_compressor.py
- Cenarios:
  - KB com 50 chunks, max_chunks=10 retorna exatamente 10
  - Chunks retornados sao os mais relevantes (maior score)
  - KB vazia retorna string vazia
  - Topico sem matches retorna chunks (com score 0, mas retorna os primeiros)
  - max_chunks=0 retorna string vazia
- Edge cases:
  - Arquivos .md vazios sao ignorados
  - Diretorio kb/ nao existe retorna string vazia
  - Topico com apenas stopwords
